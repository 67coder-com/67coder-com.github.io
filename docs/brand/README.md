# Эталон маскота

`mascot-reference.png` — маскот курса: две квадратные скобки, между ними два круглых глаза кремового цвета. Его прикладывают к каждому промпту иллюстрации, где есть маскот, с фразой «Use the attached image as the exact reference for the mascot».

Маскот не описывают словами и не перерисовывают «похоже»: генератор должен повторить именно эту форму. Скобки никогда не деформируются, у маскота нет рук, бровей, обводки и градиентов — двигаются только глаза.
