# Передача между главами

Сюда агент кладёт `handover_NN.md` после каждой главы: что студент уже знает, что ещё запрещено, где сюжет, какие справки и факты использованы. Перед новой главой агент читает все файлы.

Для глав, написанных до перехода на агента, автор кладёт сюда контейнеры из старых чатов — под именами `handover_01.md`, `handover_02.md`.
