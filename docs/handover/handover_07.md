# Глава 7 · Aritmētika un operācijas / Arithmetic and operations

## Студент теперь знает (накопительно с главы 1)
- Компиляция C++ из исходного кода в машинный код; каркас программы (`iostream`, `using namespace std;`, `main()`, `return 0;`, `;`).
- Вывод строк, чисел и переменных через `cout`, цепочки `<<`, перевод строки (`endl`, `\n`), комментарии `//` и `/* ... */`.
- Статическая типизация против динамической в Python: тип объявляется один раз при создании, обновление значения без повтора типа.
- Семейство целых чисел: `short` (2 байта), `int` (4 байта), `long`, `long long` (8 байт, суффикс `LL`), `unsigned`, переполнение.
- Вещественные типы: `float` (4 байта, суффикс `f`), `double` (8 байт), целочисленное деление `int / int` с отбрасыванием дробной части, продвижение типов с вещественным операндом (`5.0 / 2`).
- Нечисловые типы: `bool` (1 байт, `true`/`false`), `char` (1 байт, одинарные кавычки, ASCII 0–127), `std::string` (`#include <string>`, двойные кавычки, конкатенация `+`, `.length()`).
- Арифметика и операторы:
  - 5 базовых бинарных операторов: сложение `+`, вычитание `-`, умножение `*`, деление `/` и остаток от деления `%` (модуло).
  - Оператор остатка от деления `%`: работает **строго с целыми числами** (`int`, `short`, `long long`) и `char`; запрещён для вещественных чисел `double` и `float`; деление или остаток на 0 вызывает сбой программы.
  - Приоритет операций (precedence hierarchy): наивысший приоритет у скобок `()`, затем умножение, деление и остаток `*`, `/`, `%`, затем сложение и вычитание `+`, `-`. Ассоциативность слева направо. Явные скобки для документирования и надёжности вычислений.
  - Составное присваивание: `+=`, `-=`, `*=`, `/=`, `%=`. Изменение значения переменной на месте без дублирования её имени.
  - Инкремент `++` и декремент `--`: шаг на 1. Идиома счётчиков C++ (в отличие от Python, где `++` отсутствует).
