# Глава 6 · bool, char un string / bool, char, and string

## Студент теперь знает (накопительно с главы 1)
- Компиляция C++ из исходного кода в машинный код; каркас программы (`iostream`, `using namespace std;`, `main()`, `return 0;`, `;`).
- Вывод строк, чисел и переменных через `cout`, цепочки `<<`, перевод строки (`endl`, `\n`), комментарии `//` и `/* ... */`.
- Статическая типизация против динамической в Python: тип объявляется один раз при создании, обновление значения без повтора типа.
- Семейство целых чисел: `short` (2 байта), `int` (4 байта), `long` (зависит от платформы), `long long` (8 байт, суффикс `LL`).
- Знаковые (`signed`) и беззнаковые (`unsigned`) типы; целочисленное переполнение и циклический переход (wraparound).
- Вещественные типы с плавающей точкой по стандарту IEEE 754: `float` (4 байта, суффикс `f`), `double` (8 байт, стандарт по умолчанию).
- Механика целочисленного деления: `int / int` отбрасывает дробную часть (`5 / 2 = 2`), продвижение типов с вещественным операндом (`5.0 / 2 = 2.5`).
- Нечисловые типы данных:
  - `bool` (1 байт, 8 бит): принимает значения `true` и `false` (строго строчными буквами, в отличие от Python `True`/`False`); `cout` выводит `1` для `true` и `0` для `false`; 0 интерпретируется как false, любое ненулевое число — как true; почему занимает целый байт (минимальная адресуемая единица памяти шины CPU — байт, прямой доступ без битовых масок).
  - `char` (1 байт): хранит ровно один символ в одинарных кавычках (`'A'`, `'8'`, `'\\n'`); 8-битный ASCII-код под капотом (0–127); одинарные кавычки в C++ строго типизированы и не взаимозаменяемы с двойными кавычками.
  - `std::string`: последовательность символов в двойных кавычках (`"IRIS-01"`), подключается через директиву `#include <string>`; конкатенация строк оператором `+`; вычисление длины метода `.length()`; ограничение сложения чистых строковых литералов (хотя бы один операнд должен быть переменной или объектом `std::string`).

## Использовано
- **Архивная справка (`archive`, шаг `system-diagnostics`):** «Kā ASCII 1963. gadā standartizēja datoru saziņu» / «How ASCII standardized computing communication in 1963» — принятие 7-битного стандарта ASCII (ASA X3.4-1963) для устранения несовместимости кодировок (BCD, EBCDIC, 5/6-битные телеграфные коды); 128 кодов: 0–31 (управляющие), 48–57 (цифры), 65–90 (латинские заглавные), 97–122 (строчные). Источник: Computer History Museum (https://www.computerhistory.org).
- **Блок «Dziļāk» (шаг `system-diagnostics`):** «Kāpēc bool aizņem veselu baitu, nevis vienu bitu» / «Why bool takes a whole byte instead of a single bit» — побайтовая адресация современных CPU (x86-64, ARM); накладные расходы на битовые маски (AND/OR) при упаковке в 1 бит против быстрой прямой выборки байта из памяти.
