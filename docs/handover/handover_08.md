# Глава 8 · Ievade ar cin / Input with cin

## Студент теперь знает (накопительно с главы 1)
- Компиляция C++ из исходного кода в машинный код; каркас программы (`iostream`, `using namespace std;`, `main()`, `return 0;`, `;`).
- Вывод строк, чисел и переменных через `cout`, цепочки `<<`, перевод строки (`endl`, `\n`), комментарии `//` и `/* ... */`.
- Статическая типизация против динамической в Python: тип объявляется один раз при создании, обновление значения без повтора типа.
- Семейство целых чисел: `short` (2 байта), `int` (4 байта), `long`, `long long` (8 байт, суффикс `LL`), `unsigned`, переполнение.
- Вещественные типы: `float` (4 байта, суффикс `f`), `double` (8 байт), целочисленное деление `int / int` с отбрасыванием дробной части, продвижение типов с вещественным операндом (`5.0 / 2`).
- Нечисловые типы: `bool` (1 байт, `true`/`false`), `char` (1 байт, одинарные кавычки, ASCII 0–127), `std::string` (`#include <string>`, двойные кавычки, конкатенация `+`, `.length()`).
- Арифметика и операторы: `+`, `-`, `*`, `/`, `%` (только для целых чисел), приоритет операторов и скобки `()`, составное присваивание `+=`, `-=`, `*=`, `/=`, `%=`, инкремент `++` и декремент `--`.
- Интерактивный потоковый ввод с консоли:
  - Поток `cin` из `<iostream>`: чтение данных из клавиатурного буфера терминала в типизированные переменные.
  - Оператор извлечения (extraction operator) `>>`: направлен внутрь программы (`cin >> variable;`), противоположно направлению вывода `cout <<`.
  - Автоматический разбор типов: `cin >> int` читает числовые цифры до пробела/буквы; `cin >> double` разбирает вещественные числа; ручное приведение типов (в отличие от `int(input())` в Python) не требуется.
  - Цепочки ввода: `cin >> a >> b;` считывает последовательные значения, разделённые пробелами, табуляцией или нажатием Enter.
  - Ограничение `cin >> string`: считывает только одно слово до первого пробельного символа.
  - Построчный ввод: `getline(cin, str)` считывает всю строку текста целиком, включая внутренние пробелы, до нажатия клавиши Enter.
- **Финал Блока 1 («Pamodināšana»):** студент полностью владеет синтаксисом линейных программ на C++, типами данных, арифметикой и консольным вводом-выводом.

## Миссия
- **Активный аппарат:** лёгкий разведчик IZLŪKS «Sigma».
- **Что произошло:** дрон Sigma отправлен на картографирование плато Mawrth Vallis. Вместо зашитых в код констант оператор базы ввёл полётные параметры с терминала базы IRIS: название целевого сектора («Mawrth Vallis») через `getline`, дистанцию (180 км) и расчётную скорость (60 км/ч) через `cin >>`. Программа рассчитала время вылета (3 часа) и передала подтверждение в полётный манифест.
- **Что ведёт к следующей главе:** дрон Sigma поднялся в воздух и удаляется от базы. По мере удаления задержка радиосигнала между аппаратом и оператором начинает нарастать (достигая 20 минут в один конец). Дрон больше не может управляться вручную каждым шагом — в Главе 9 («Nosacījumi if / else») мы наделяем бортовой компьютер способностью принимать автономные решения на основе показаний сенсоров.

## Использовано
- **Архивная справка (`archive`, шаг `operator-console-prep`):** «Kā standarta plūsmas Unix 1972. gadā mainīja skaitļošanu» / «How Unix standard streams transformed computing in 1972» — разработка Кена Томпсона и Денниса Ритчи (Bell Labs) концепции стандартных потоков `stdin`, `stdout`, `stderr` в Unix; унификация работы с терминалом, скриптами и файлами; перегрузка Бьёрном Страуструпом операторов `<<` и `>>` в C++ как интуитивных стрелок потока. Источник: Dennis Ritchie, 'The Evolution of the Unix Time-sharing System'; Bjarne Stroustrup, 'The Design and Evolution of C++' (Addison-Wesley, 1994).
