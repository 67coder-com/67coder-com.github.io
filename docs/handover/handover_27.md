# Глава 27 · Struktūras (struct) / Structures (struct)

## Студент теперь знает (накопительно с главы 1)
- Фундамент C++ (Главы 1–24): типы, циклы, массивы (1D, 2D), векторы, функции.
- Строки `std::string` (Глава 25) и форматирование `<iomanip>` (Глава 26).
- Пользовательские составные структуры данных **`struct`**:
  - Синтаксис объявления: ключевое слово `struct`, фигурные скобки, разнородные поля, **обязательная точка с запятой `;` в конце**.
  - Размещение в памяти: непрерывный блок полей, оператор `sizeof()`.
  - Инициализация списком значений `{...}` по порядку объявления полей.
  - Доступ к полям через оператор «точка» (`object.field`).
  - Семантика передачи структур в функции:
    - По значению (`Drone d`): полное копирование всех полей, вызывающий объект изолирован.
    - По ссылке (`Drone &d`): модификация полей на месте без накладных расходов.
    - По константной ссылке (`const Drone &d`): высокопроизводительное чтение без копирования.
  - Моделирование автономных состояний бортовых систем («Один дрон = одна структура данных»).

## Миссия
- **Активный аппарат:** **IZLŪKS «Sigma»**.
- **Что произошло:** Архитектурная реорганизация бортового ПО Сигмы. Вместо десятка разрозненных переменных (`drone_id`, `battery`, `altitude`, `is_safe`) студент объединил параметры дрона в единый тип данных — структуру `FlightState`. Написаны сервисные функции для симуляции расхода батареи при наборе высоты (`update_flight`) и генерации сводных отчетов телеметрии (`print_report`).
- **Что ведёт к следующей главе:** Один дрон теперь инкапсулирован в структуру. Но флот базы IRIS состоит из трех аппаратов: Sigma, Delta и Omega. В Главе 28 мы объединяем все три дрона в единый массив структур — бортовую эскадру.
