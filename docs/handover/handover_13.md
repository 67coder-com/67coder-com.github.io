# Глава 13 · Cikls while / The while loop

## Студент теперь знает (накопительно с главы 1)
- Базовый синтаксис C++, типы данных, арифметику, ввод/вывод (`cin`, `cout`).
- Ветвления и логику: `if / else`, логические операторы (`&&`, `||`, `!`), `switch / case`, тернарный оператор `?:`.
- Циклические конструкции:
  - Цикл с предусловием `while (condition) { body }`:
    - Проверка условия ДО входа в тело цикла.
    - Возможность 0 итераций, если условие изначально ложно.
    - Опасность бесконечного цикла, если переменные условия не обновляются внутри тела.
  - Цикл с постусловием `do { body } while (condition);`:
    - Гарантированное выполнение тела цикла как минимум один раз.
    - Проверка условия ПОСЛЕ итерации.
    - Обязательный завершающий семиколон `;` после круглых скобок.
  - Потоковое чтение данных переменной длины до значения-сигнала (sentinel value) через `while (cin >> val)` / `while (val != sentinel)`.

## Миссия
- **Активные аппараты:** лёгкий разведчик IZLŪKS «Sigma» и тяжёлый исследователь KARTOGRĀFS «Delta».
- **Что произошло:** После стихания пылевой бури на рассвете дрон Sigma проходит предполётную подготовку. Прогрев двигателя и набор рабочего давления в гидравлических магистралях происходят циклически до достижения целевой температуры. Для дрона Delta реализован импульсный цикл зарядки накопительного конденсатора лидара на базе `do-while`.
- **Что ведёт к следующей главе:** Дроны освоили циклы с условием. Но когда маршрут разведки состоит из заранее известного числа точек (например, 10 координатных секторов), эффективнее использовать компактный цикл со счётчиком: `for` (Глава 14).
