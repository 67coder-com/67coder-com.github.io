## Студент теперь знает (накопительно с главы 1)
- Фундамент C++ (Главы 1–24): базовые типы, циклы, массивы (1D, 2D), векторы, функции (by-value, by-reference, const-reference, overloading).
- Стандартный класс строк **`std::string`** из `<string>`:
  - Память и длина: методы `.length()` и `.size()`, непрерывный буфер символов, индексация `str[i]` от 0 до $N-1$.
  - Поиск подстрок и разделителей: метод `.find(' ')` и `.find("...")`, возвращаемое значение `size_t` и проверка на сигнальную константу отсутствия **`string::npos`**.
  - Вырезка фрагментов: метод `.substr(pos, count)` и форма от позиции до конца строки `.substr(pos)`.
  - Преобразование текста в числа: функции `stoi()` (String to Integer) и `stod()` (String to Double).
  - Построчный ввод с пробелами через `getline(cin, line)`.
  - Передача строк в функции по константной ссылке `const string &` для исключения копирования.

## Миссия
- **Активный аппарат:** **IZLŪKS «Sigma»**.
- **Что произошло:** Начало 4-го блока автономных операций дальнего радиуса действия. Сигма наладила оптический канал связи с Землей для приема пакетных директив управления полетом. Студент написал бортовой модуль синтаксического анализа текстовых протоколов: выделение глаголов команд (`THRUST`, `ELEVATION`, `YAW`), парсинг числовых параметров через поиск разделителей `:` и ` `, конвертацию в бортовые координаты и проверку целостности CSV-телеметрии.
- **Что ведёт к следующей главе:** Пакеты команд успешно расшифрованы, но для отправки отчетов обратно на Землю разрозненные числа необходимо форматировать в строгие колонки телеметрических таблиц. В главе 26 мы подключаем библиотеку манипуляторов вывода `<iomanip>`.
