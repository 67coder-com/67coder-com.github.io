# Глава 30 · Kļūdu apstrāde (errors) / Error Handling: Input Defense

## Студент теперь знает (накопительно с главы 1)
- Фундамент C++ (Главы 1–24): базовые типы, управляющие конструкции, массивы (1D, 2D), векторы, функции.
- Расширение языка (Блок 4, Главы 25–29): строки `std::string`, форматирование `<iomanip>`, структуры `struct`, массивы структур, файловые потоки `<fstream>`.
- Комплексная система защитного программирования и обработки ошибок потоков:
  - Механика ошибки потока: возникновение `failbit` при несоответствии типов данных.
  - Последствия: блокировка потока ввода (`cin.fail() == true`) и потеря последующих данных.
  - Протокол восстановления потока в 3 шага:
    1. `cin.clear()` — сброс флагов ошибок.
    2. Считывание и сброс мусорных символов из буфера в промежуточную строку (`string junk; cin >> junk;`).
    3. Применение резервного значения (`fallback value`) по умолчанию.
  - Санитизация диапазонов физических величин: ограничение границ (`clamping`), фильтрация граничных кодов аппаратных сбоев (`sentinel error codes`, например `-999`).
  - Принцип отсутствия тяжелых исключений: предпочтение детерминированных проверок возврата (`return codes`) вместо `try/catch` в бортовом встроенном ПО реального времени.

## Миссия
- **Активный аппарат:** **IZLŪKS «Sigma»**.
- **Что произошло:** Попадание Сигмы в интенсивную марсианскую пылевую бурю с электростатическими разрядами. Телеметрическая шина дрона начала передавать искаженные данные и сбойные коды `-999`. Студент реализовал отказоустойчивый контроллер авионики: перехват зависаний потока через `cin.fail()`, сброс флагов `cin.clear()`, валидацию допустимых диапазонов датчиков и автоматическое переключение на резервные каналы без аварийной остановки винтов.
