# Глава 9 · Nosacījumi if / else / Conditions: if / else

## Студент теперь знает (накопительно с главы 1)
- Компиляция C++ из исходного кода в машинный код; каркас программы (`iostream`, `using namespace std;`, `main()`, `return 0;`, `;`).
- Вывод строк, чисел и переменных через `cout`, цепочки `<<`, перевод строки (`endl`, `\n`), комментарии `//` и `/* ... */`.
- Статическая типизация против динамической в Python: тип объявляется один раз при создании, обновление значения без повтора типа.
- Семейство целых чисел: `short` (2 байта), `int` (4 байта), `long`, `long long` (8 байт, суффикс `LL`), `unsigned`, переполнение.
- Вещественные типы: `float` (4 байта, суффикс `f`), `double` (8 байт), целочисленное деление `int / int` с отбрасыванием дробной части, продвижение типов с вещественным операндом (`5.0 / 2`).
- Нечисловые типы: `bool` (1 байт, `true`/`false`), `char` (1 байт, одинарные кавычки, ASCII 0–127), `std::string` (`#include <string>`, двойные кавычки, конкатенация `+`, `.length()`).
- Арифметика и операторы: `+`, `-`, `*`, `/`, `%` (только для целых чисел), приоритет операторов и скобки `()`, составное присваивание `+=`, `-=`, `*=`, `/=`, `%=`, инкремент `++` и декремент `--`.
- Интерактивный потоковый ввод с консоли: `cin >>`, автоматический разбор типов, цепочки ввода `cin >> a >> b;`, `getline(cin, str)` для чтения строк с пробелами.
- Операторы сравнения (relational / comparison operators):
  - Шесть базовых операторов: `==` (равно), `!=` (не равно), `<` (меньше), `>` (больше), `<=` (меньше или равно), `>=` (больше или равно).
  - Сравнение возвращает логический тип `bool`: `true` (выводится в консоль как 1) или `false` (выводится как 0).
  - Различие между `=` (присваивание значения) и `==` (сравнение без изменения операндов).
- Условные конструкции и ветвление (branching):
  - Одиночный `if (condition) { ... }`: выполнение тела условия только при истинности выражения; пропуск тела при `false`.
  - Запрет точки с запятой сразу после круглых скобок `if (cond);` (преждевременное завершение пустого оператора).
  - Двустороннее ветвление `if (condition) { ... } else { ... }`: выбор между двумя взаимоисключающими путями, гарантированное выполнение ровно одного блока.
  - Каскадное ветвление `if ... else if ... else`: последовательная проверка условий сверху вниз, выход при первом совпадении (`first match wins`), страховочный блок `else`.

## Миссия
- **Активный аппарат:** лёгкий разведчик IZLŪKS «Sigma».
- **Что произошло:** дрон Sigma отправился в дальний автономный полёт к каньону Mawrth Vallis. По мере удаления задержка радиосвязи со станцией IRIS достигает 22 минут в один конец, исключая возможность прямого ручного управления. Дрон научился самостоятельно реагировать на показания сенсоров: подавать сигнал тревоги при опасном снижении (`altitude < 20`), переключать режим полёта при низком заряде батареи (`battery >= 25`) и управлять скоростью сближения с препятствиями по лазерному дальномеру (`dist <= 10`, `dist <= 50`).
- **Что ведёт к следующей главе:** в полёте Sigma сталкивается с ситуациями, когда решение зависит от нескольких параметров одновременно (например, посадка разрешена только если заряд батареи в норме И площадка ровная И скорость ветра допустима). В Главе 10 («Loģiskās operācijas») мы объединим одиночные сравнения с помощью логических операторов `&&`, `||` и `!`.
