# Глава 20 · Funkcijas: pamati / Functions: The Basics

## Студент теперь знает (накопительно с главы 1)
- Фундамент C++: типы данных, ввод/вывод `cin`/`cout`, ветвления (`if/else`, `switch/case`, `?:`, логические операторы).
- Циклы: `while`, `do-while`, `for`, операторы `break` и `continue`.
- Массивы (1D и 2D) и динамические массивы (`std::vector`).
- Функции (базовые концепции):
  - Модульная декомпозиция: вынос повторяющихся формул и действий в именованные подпрограммы.
  - Анатомия функции:
    - Заголовок (сигнатура): тип возвращаемого значения, идентификатор функции, список формальных параметров в круглых скобках `(тип имя, ...)`.
    - Тело функции в фигурных скобках `{ ... }`.
    - Оператор `return`: вычисление результата, передача его вызывающему коду и немедленное завершение работы функции.
  - Процедуры без возвращаемого значения: тип `void`, невозможность присваивания результата `void` в переменную, ранний выход через `return;`.
  - Вызов функции: передача фактических аргументов по значению (копирование).
  - Порядок объявления: компилятор должен знать о функции до её вызова:
    - Определение функции перед `main()`.
    - Прототип (forward declaration) перед `main()` с реализацией ниже `main()`.
  - Предикатные функции, возвращающие `bool` (проверка диапазона безопасных высот).

## Миссия
- **Активные аппараты:** флот IRIS: разведчик **IZLŪKS «Sigma»**, картограф **KARTOGRĀFS «Delta»** и грузовой дрон **KRAVAS «Omega»**.
- **Что произошло:** С увеличением задач флота код бортовых компьютеров стал слишком объемным для единой функции `main`. Студент запрограммировал модульный инструментарий авионики: подпрограмму расчета расхода топлива двигателей `calculate_fuel`, процедуру проверки запаса батареи `battery_margin` и предикат безопасности эшелона полета `is_safe_altitude`.
- **Что ведёт к следующей главе:** Сейчас все параметры передаются по значению (копируются). Но дронам требуется обновлять телеметрию прямо в памяти и передавать тяжелые массивы без копирования. В Главе 21 изучается **Передача параметров: по ссылке и const-ссылке**.
