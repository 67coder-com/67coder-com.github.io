# Глава 26 · Izvades formatēšana (iomanip) / Output Formatting with <iomanip>

## Студент теперь знает (накопительно с главы 1)
- Фундамент C++ (Главы 1–24): типы, циклы, массивы (1D, 2D), векторы, функции.
- Строки `std::string` (Глава 25): методы `.length()`, `.find()`, `string::npos`, `.substr()`, `stoi()`, `stod()`.
- Библиотека манипуляторов ввода-вывода **`<iomanip>`**:
  - Ширина поля: манипулятор `setw(width)`.
  - Фундаментальное свойство: `setw()` является **одноразовым** (single-shot) — сбрасывается в 0 сразу после вывода ближайшей переменной.
  - Позиционирование и выравнивание: манипуляторы `left` и `right` (по умолчанию `right`), их персистентность («липкость»).
  - Точность дробных чисел: связка `fixed` + `setprecision(digits)` для вывода строго фиксированного числа знаков после запятой (в отличие от `setprecision` без `fixed`, который считает общее число значащих цифр).
  - Построение выровненных табличных отчетов телеметрии с заголовками и строками.

## Миссия
- **Активный аппарат:** **IZLŪKS «Sigma»**.
- **Что произошло:** Модернизация бортовой системы отчетности Сигмы для Центра управления полетами на Земле. Неформатированный поток телеметрии порождал «гуляющие» колонки и разное количество знаков после запятой, что мешало операторам быстро считывать критические параметры при посадке. Студент подключил `<iomanip>` и создал генератор ровных телеметрических таблиц с фиксированной шириной колонок (`setw`), выравниванием (`left`/`right`) и жесткой точностью до 2 знаков (`fixed << setprecision(2)`).
- **Что ведёт к следующей главе:** Телеметрия форматируется идеально, но переменные дрона (координаты X/Y, заряд батареи, скорость, статус) до сих пор хранятся разрозненно. В Главе 27 мы объединяем все параметры дрона в единый пользовательский тип — структуру `struct Drone`.
