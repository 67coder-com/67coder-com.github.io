# Глава 18 · Divdimensiju masīvi — Marsa karte / 2D Arrays: Mars Surface Map

## Студент теперь знает (накопительно с главы 1)
- Фундамент C++: типы данных, консольный ввод/вывод `cin`/`cout`, ветвления (`if/else`, `switch/case`, `?:`, логические операторы).
- Циклы: `while`, `do-while`, `for`, операторы `break` и `continue`.
- Массивы (1D): синтаксис, индексация с нуля, обход, поиск экстремумов и сумм.
- Двумерные массивы (2D Arrays / Матрицы):
  - Понятие матрицы как массива массивов, непрерывно расположенных в памяти по строкам (row-major order).
  - Объявление с двумя размерностями: `type name[ROWS][COLS];`.
  - Координатная индексация `[row][col]`: первый индекс — строка (вертикаль), второй — колонка (горизонталь).
  - Инициализация вложенными фигурными скобками `{ {..}, {..} }` или нулями `{0}`.
  - Стандартная идиома обхода матрицы вложенными циклами `for`:
    - Внешний цикл по строкам `for (int r = 0; r < ROWS; r++)`.
    - Внутренний цикл по колонкам `for (int c = 0; c < COLS; c++)`.
  - Форматированный вывод матрицы в виде таблицы с разделением пробелами и переходом на новую строку (`endl`) в конце каждой строки.
  - Алгоритмы на матрицах:
    - Поиск двумерного экстремума (пика высоты) с отслеживанием координат `(peak_r, peak_c)`.
    - Построчный аудит (сброс и подсчёт суммы отдельно для каждой строки `row_sum`).
    - Диагональный срез (проход по главной диагонали `map[i][i]`).
    - Классификация ячеек (подсчёт безопасных и опасных зон).

## Миссия
- **Активные аппараты:** картограф **KARTOGRĀFS «Delta»**, разведчик **IZLŪKS «Sigma»** и грузовой дрон **KRAVAS «Omega»**.
- **Что произошло:** Delta провела лазерную альтиметрию кратерного бассейна Mawrth Vallis и построила цифровую модель рельефа (DEM) в виде матрицы высот. Студент запрограммировал поиск пика высоты для установки ретранслятора, расчёт радиационного фона по секторам и фильтрацию матрицы шероховатости грунта для выбора безопасной посадочной площадки дрона Sigma.
- **Что ведёт к следующей главе:** Двумерные матрицы позволяют хранить координатные сетки фиксированного размера. Но при разведке новых каньонов число контрольных точек маршрута заранее неизвестно. В Главе 19 изучается **`std::vector` (Динамические массивы)**, умеющий расти по мере поступления данных.
