# Глава 28 · Struktūru masīvi — eskadra / Arrays and Vectors of Structs

## Студент теперь знает (накопительно с главы 1)
- Фундамент C++ (Главы 1–24): базовые типы, управляющие конструкции, массивы (1D, 2D), векторы, функции.
- Строки `std::string` (Глава 25), форматирование `<iomanip>` (Глава 26), структуры `struct` (Глава 27).
- Контейнеры структур (массивы и динамические векторы `vector<Drone>`):
  - Порядок синтаксиса доступа: **сначала индекс элемента в квадратных скобках, затем поле через точку**: `fleet[i].battery`.
  - Защита от частой ошибки: запрет ошибочной формы `fleet.battery[i]`.
  - Непрерывное размещение в памяти последовательных объектов структуры.
  - Динамическое масштабирование флота через `fleet.push_back({id, bat, alt})`.
  - Алгоритмы обхода флота:
    - Агрегация суммарных метрик (суммарная энергия эскадры).
    - Поиск экстремумов (дрон с минимальной батареей или максимальной высотой).
    - Фильтрация по составным критериям готовности к миссии (`battery >= 50 && altitude >= 0`).
  - Передача эскадры в функции: модификация на месте по `vector<Drone> &` и высокопроизводительный анализ по `const vector<Drone> &`.

## Миссия
- **Активные аппараты:** Все три дрона флота IRIS: **IZLŪKS «Sigma»**, **KARTOGRĀFS «Delta»**, **KRAVAS «Omega»**.
- **Что произошло:** Объединение разрозненных аппаратов в единую эскадру. Студент создал координационный центр флота на базе `vector<Drone>`, позволяющий синхронно анализировать энергопотребление всех трех аппаратов, находить лидера по высоте и проводить пакетную калибровку батарей перед скоординированным вылетом в глубинный марсианский каньон.
- **Что ведёт к следующей главе:** Вся эскадра синхронизирована, но оперативная память сбрасывается при отключении питания или перезагрузке бортового компьютера. В Главе 29 мы учим флот записывать маршруты и телеметрию в постоянные файлы миссии на диске с помощью `<fstream>`.
