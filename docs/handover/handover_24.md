# Глава 24 · KONTROLPUNKTS: Bāzes sertifikācija / Checkpoint: Core Certification

## Студент теперь знает (накопительно с главы 1)
- Полный фундаментальный корпус процедурного программирования на C++ (Блоки 1, 2, 3: Главы 1–24):
  - Базовые типы, размеры, ввод/вывод `cin`/`cout`, арифметические операторы, деление нацело и остаток `%`.
  - Управляющие структуры: ветвления (`if/else`, `switch/case`, тернарный оператор `?:`, булева алгебра `&&`, `||`, `!`).
  - Все разновидности циклов: детерминированные `for`, сигнальные `while`, гарантированные `do-while`, управление итерациями `break` и `continue`.
  - Массивы фиксированного размера: 1D массивы `int arr[N]`, многомерные матрицы `int grid[R][C]`, алгоритмы обхода диагоналей и агрегации строк.
  - Динамические последовательности: контейнер `std::vector<T>`, методы `.push_back()`, `.size()`, `.empty()`.
  - Функции и модульная декомпозиция:
    - Прототипы и объявления.
    - Передача параметров по значению (копия, чистые предикаты).
    - Передача по ссылке `&` (модификация аргументов, in-place калибровка, множественный возврат).
    - Передача по константной ссылке `const &` (высокопроизводительный обход тяжелых контейнеров без копирования).
    - Перегрузка функций (`function overloading`) по типам и числу аргументов.
    - Области видимости (`scope`) и время жизни переменных.

## Карантин для следующей главы
- Открывается Блок 4 (Автономия, главы 25–32)!

- Структуры `struct` разрешены с главы 27.
- Файловые потоки `<fstream>` разрешены с главы 29.

## Миссия
- **Активные аппараты:** Излётный флот IRIS в полном составе: **IZLŪKS «Sigma»**, **KARTOGRĀFS «Delta»**, **KRAVAS «Omega»**.
- **Что произошло:** Квалификационная аттестация оператора бортовых систем. Студент подтвердил владение полным стеком базового C++, пройдя диагностические тесты (трассировка сложных циклов, аудит ошибок ссылочной передачи, матричные вычисления, сборка перегруженных диспетчеров) и написав комплексный контроллер миссии флота (`capstone-fleet-mission-director`).
- **Что ведёт к следующей главе:** Сертификация подтверждена. Флот переходит в автономный режим дальнего радиуса действия в Блоке 4. Первая задача — парсинг текстовых телеметрических протоколов и команд миссии (`std::string`) в Главе 25.
