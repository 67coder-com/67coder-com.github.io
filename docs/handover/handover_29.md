# Глава 29 · Darbs ar failiem (fstream) / File Operations with <fstream>

## Студент теперь знает (накопительно с главы 1)
- Фундамент C++ (Главы 1–24): базовые типы, управляющие конструкции, массивы (1D, 2D), векторы, функции.
- Строки `std::string` (Глава 25), форматирование `<iomanip>` (Глава 26), структуры `struct` (Глава 27), массивы структур (Глава 28).
- Работа с файловыми потоками библиотеки **`<fstream>`**:
  - Потоки чтения **`std::ifstream`**: чтение токенов через `>>`, построчное чтение через `getline()`, идиоматический цикл обхода до конца файла `while (fin >> x)`.
  - Потоки записи **`std::ofstream`**: форматированный вывод в файл через `<<`, сброс буферов на физический диск.
  - Критическое правило защитного программирования: обязательная проверка открытия файла через **`.is_open()`** перед любыми операциями.
  - Корректное освобождение дескрипторов операционной системы через **`.close()`**.
  - Унифицированная модель потоков C++: одинаковый синтаксис для терминала (`cin`/`cout`) и дисковых файлов (`ifstream`/`ofstream`).

## Миссия
- **Активный аппарат:** **IZLŪKS «Sigma»**.
- **Что произошло:** Оснащение Сигмы долговременной энергонезависимой памятью («черным ящиком» миссии). Во время пылевых бурь и ночных перезагрузок бортового компьютера данные в оперативной памяти сбрасываются. Студент настроил модуль записи журналов на диск с помощью `<fstream>`, внедрил валидацию доступности файлов `.is_open()` и алгоритм буферизации маршрутных точек.
- **Что ведёт к следующей главе:** Файлы сохраняются, но при сбоях датчиков или передаче искаженных пакетов поток ввода переходит в состояние ошибки (`fail state`). В Главе 30 мы учим Сигму перехватывать и сбрасывать ошибки ввода с помощью `cin.fail()` и восстанавливать нормальную работу без аварийного падения дрона.
