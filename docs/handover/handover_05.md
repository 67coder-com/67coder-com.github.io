# Глава 5 · Daļskaitļi un precizitāte / Floating-point numbers and precision

## Студент теперь знает (накопительно с главы 1)
- Компиляция C++ из исходного кода в машинный код; каркас программы (`iostream`, `using namespace std;`, `main()`, `return 0;`, `;`).
- Вывод строк, чисел и переменных через `cout`, цепочки `<<`, перевод строки (`endl`, `\n`), комментарии `//` и `/* ... */`.
- Статическая типизация против динамической в Python: тип объявляется один раз при создании, обновление значения без повтора типа.
- Семейство целых чисел: `short` (2 байта), `int` (4 байта), `long` (зависит от платформы), `long long` (8 байт, суффикс `LL`).
- Знаковые (`signed`) и беззнаковые (`unsigned`) типы; целочисленное переполнение и циклический переход (wraparound).
- Вещественные типы с плавающей точкой по стандарту IEEE 754:
  - `float` (4 байта, 32 бита, ~7 значащих цифр, литеральный суффикс `f` — `3.73f`);
  - `double` (8 байт, 64 бита, ~15—17 значащих цифр, стандартный выбор для десятичных чисел в современном C++).
- Механика целочисленного деления: если оба операнда целые числа (`int`), операция отбрасывает дробную часть без округления (`5 / 2 = 2`, `1 / 4 = 0`).
- Продвижение типов в выражениях: если хотя бы один операнд вещественный (`5.0 / 2` или `5 / 2.0`), C++ выполняет вещественное деление с сохранением дробной части (`2.5`).
- Ловушка `double d = 5 / 2;`: выражение `5 / 2` сначала вычисляется как целое `2`, и лишь затем преобразуется в `2.0` при присваивании.
- Ограничения двоичного представления: десятичные дроби вроде 0.1 в двоичной системе становятся бесконечными периодическими дробями и хранятся с машинным округлением.
