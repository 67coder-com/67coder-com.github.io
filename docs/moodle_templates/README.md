# Шаблоны описаний Moodle · стиль RNU

Цвета сняты со стилей rnu.lv: основной `#1A2F59`, акцент `#C3C925`, текст `#414141`, линии `#DDE3EE`, фон блоков `#F8F8F8`, ссылки `#1863DC`.

| Файл | Куда |
| --- | --- |
| `section-0.lv.html` | описание общего раздела курса |
| `block-1.lv.html` … `block-4.lv.html` | описания разделов четырёх блоков |
| `exam.lv.html` | описание раздела «Eksāmens» |
| `lecture.lv.html` | шаблон описания подраздела лекции |

В шаблоне лекции заменить: `[rezultāts …]`, `[X] [N] [M]`, номер главы `N` в ссылке и `SAITE-UZ-PDF` — адресом файла «Teorija (PDF)» в этом подразделе.

В общем разделе `SAITE-UZ-ZIŅOJUMU` — ссылку «Uzrakstīt pasniedzējai» брать из текущего описания в Moodle, она уже правильная.
