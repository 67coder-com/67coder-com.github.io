# Правила для агента · 67coder

Этот репозиторий — сайт 67coder.com на GitHub Pages. Контент уроков пишет и утверждает автор курса в чате. Твоя работа — **перенести утверждённый контент в файлы**, проверить его и открыть pull request. Ты не автор: тексты, код примеров и ответы ты не переписываешь.

Полный формат файлов урока — `docs/lesson_format.md`. Читай его перед каждой задачей.

## Что не трогать никогда

`index.html`, `runner.worker.js`, `fonts/`, `tools/`, `.github/`, `CNAME`, `AGENTS.md`, `docs/` — только если в задаче прямо написано, что их нужно изменить.

## Задача «Новая глава / правки»

В теле задачи — пакет главы. Каждый файл — строка `Файл: путь` и сразу под ней блок кода:

    Файл: content/cpp/lesson-03.json
    ```json
    { ... }
    ```

1. Запиши каждый файл по указанному пути **ровно как есть**. Если файл уже существует — замени целиком.
2. Исправлять можно только форму, не содержание: синтаксис JSON, экранирование. Каждое такое исправление перечисли в описании pull request.
3. В `content/cpp/course.json` у этого урока поставь `"draft"` — список языков, для которых есть файлы `lesson-NN.<язык>.json`, например `["lv", "en"]`. Поле `"locales"` **не меняй**: урок остаётся черновиком и студентам не виден.
4. SVG-схемы из пакета — в `content/cpp/assets/`.
5. Всё, что помечено как Moodle, — **не записывай никуда**. Репозиторий публичный: вопросы экзамена, попав сюда, станут видны студентам.

## Задача «Картинки для главы»

В задаче — заголовки с именами файлов (`### l03-why-cpp.jpg`) и под каждым приложенная картинка.

1. Скачай каждую картинку и сохрани в `content/cpp/assets/` **под именем из заголовка**.
2. Если приложенный файл не JPEG, а имя в заголовке оканчивается на `.jpg` — сохрани с правильным расширением (`.png`, `.webp`) и в `lesson-NN.json` у этого шага пропиши `"image": "assets/<имя>"`.
3. Больше ничего не меняй.

## Задача «Опубликовать главу»

В `content/cpp/course.json` у урока перенеси языки из `"draft"` в `"locales"` и удали `"draft"`. Больше ничего не меняй.

## Всегда

- Перед pull request запусти `node tools/validate.mjs`. Если есть ОШИБКИ — исправь только форму и запусти снова. Если ошибка в содержании (например, правильного ответа нет среди вариантов) — не выдумывай ответ: опиши ошибку в pull request, автор исправит в чате.
- Одна задача — один pull request. Ветка: `lesson-NN-<что-сделано>`.
- В описании pull request: список файлов, результат проверки и ссылка на предпросмотр:
  `https://67coder.com/?preview#/course/cpp/lv/lesson/N`
